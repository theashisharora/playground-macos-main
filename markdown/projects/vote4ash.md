# Vote4Ash

**Online voting platform** · [vote4ash.vercel.app](https://vote4ash.vercel.app/)

Vote4Ash is a responsive online voting application that makes elections for student organizations and community polls ==secure and easy to use==.

## Highlights

- Firebase Authentication with ==role-based access control==.
- Firestore data storage with ==real-time result updates==.
- Fully responsive UI, deployed on Vercel.

## Tech stack

Next.js · React · Tailwind CSS · Firebase (Authentication & Firestore) · Vercel
