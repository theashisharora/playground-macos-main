# About This Site

This is ==Ashish Arora's interactive portfolio==, designed to look and feel like a macOS desktop. Open the apps in the Dock to explore my projects, browse my links in Safari, or try the Terminal (type `help`).

It's built with [React](https://react.dev/), [Zustand](https://zustand-demo.pmnd.rs/) and [UnoCSS](https://unocss.dev/), and bundled with [Vite](https://vitejs.dev/).

The site is based on an open-source macOS-style portfolio template (MIT License), which I've personalized with my own content and design.
