# Go2Gether

**Carpooling & transit web app** · BramHacks hackathon · [live demo](https://theashisharora.github.io/go2gether/)

Go2Gether connects people heading to similar destinations so they can ==share rides, socialize, and cut travel costs==.

## Highlights

- ==Real-time ride matching== with location/API functionality.
- Secure data handling for a reliable, safe carpooling experience.
- Responsive interface with dynamic user interactions.

## Tech stack

HTML · CSS · SCSS · JavaScript · Bootstrap · APIs
