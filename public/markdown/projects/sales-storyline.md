# Sales Storyline

**AI sales intelligence platform** · built at Naryant · *private repository*

Sales Storyline is an ==AI-powered web application== that combines HubSpot deal information with Google Drive content to automatically generate structured sales insights, storylines, and client-ready material.

## What I built

- Developed the full-stack application end to end.
- Integrated multiple business data sources: the **HubSpot API** for deal data, and a **Google Drive connector / MCP** for documents.
- Implemented ==AI-assisted content generation== with editing, saving, and export features to speed up sales preparation.

## Tech stack

React · TypeScript · CSS · C# · ASP.NET Core · SQL Server · OpenAI API · HubSpot API · Google Drive / MCP
